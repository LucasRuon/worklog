## Reproduzir nesta máquina

Para consultar os dados já registrados:

```sh
npm run dev
```

Em outro terminal do Worklog:

```sh
npm run cli -- open
```

O servidor retoma a observação da sessão selecionada a cada segundo. Com o servidor fechado, o OpenCode preserva seus registros nativos; o Worklog retoma ao iniciar ou executar:

```sh
npm run cli -- collect
```

Para repetir a verificação completa com o navegador:

```sh
npm run smoke:opencode -- --root "/Users/lucasruon/Downloads/Sistemas/Worklog" --session ses_e52e1e695ffehIwDvVlVDDW3qt
```

As próximas sessões podem ser conectadas explicitamente com `opencode connect`. O coletor de eventos/plugin previsto em T13 ampliará a cobertura; o parser atual é vinculado ao armazenamento de OpenCode 1.19.5.
